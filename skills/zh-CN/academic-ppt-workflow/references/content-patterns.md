## 内容与备注

页面突出关键事实，详细统计范围、计算方法、来源定位及展开解释在构建时写入对应页的 **PPT 讲稿备注**，外部 Markdown 不能替代实际备注。仅交付大纲时保存待导入备注，不声称已写入 PPT。页面可用短来源编号，完整定位放备注。

删除说明后会改变数字或结论含义，则保留准确名词或最短必要限定；其余解释可入备注。例如索款金额不等于已发生损失，预计收益不等于实测收益。事实、推断、自拟情境和示意数据分别记录；画面容易被误认作真实成果时，页面标明“示意”等性质，不强制每页加警告栏。

## 社会事件案例

- **适用：** 用来源可靠、与论点相关的真实事件说明实际影响；多个案例补充不同后果或条件，研究演示不冒充社会事件。
- **叙述与必要信息：** 时间/背景 → 关键过程 → 已证实的影响 → 与本主题的关系。突出经济损失、泄露规模、服务中断或实际收益；没有可靠数字时突出有依据的定性后果，不为视觉效果夸大数字。区分多因素事件与单一技术的归因。
- **页面与表现：** 通常一事件一页，复杂链条可拆页；“事件名：关键变化/后果”的同组标题便于比较。过程与新闻/报告图可左右或上下排列，影响作为视觉重点，不限定固定比例。
- **素材与备注：** 每案关联展示意图、候选或待选状态、占位区域/比例及填图阶段；未找到时保留暂定占位，核实后校准。摘要与生成提示继承计划，按 [真实配图与占位](visual-production.md#真实配图与占位) 生成占位、后续填图。完整来源、数字口径和归因解释入备注，必要限定留在页面。
- **验收与例外：** 过程、影响与证据相互对应，潜在风险不当作既成损失；报道图片不自动证明数字。配图不适用或用户要求省略须有具体依据，“没有素材清单”或“找不到图片”不等于已完成。

## 方法与原理

- **适用：** 解释技术、研究方法、算法、操作机制或复杂业务流程如何工作。面向非专家，或涉及抽象对象、多步变化时，默认采用“原理说明＋具体示例”单元。
- **叙述与必要信息：** 原理交代前提、作用/修改对象、目标、关键步骤、输出与局限；有迭代则说明候选/更新、反馈和停止条件。例子给定具体输入或情境，逐步展示关键中间变化、结果及其与原理步骤的对应。只写“给若干示例”“重复直到成功”或放问号，不算具体例解。
- **页面与表现：** 复杂内容默认拆为原理页与示例页；原理用结构图/流程，例子用实例流程、时间线、输入输出对照或一次迭代。标题可为“方法一：核心机制”“方法一示例：一次输入如何变化”；并列方法沿用相近句式与说明顺序，所用图形适应各自关系。
- **可比条件：** 同组方法尽量固定示例背景、目标和输入；条件无法一致时解释差异。每种需例解的方法均有对应示例，不能只为其中一种补例子。综合练习用于检验理解，只有实际完整展示了各方法过程，才可承担其示例功能。
- **备注：** 写推导、细节、简化假设与选讲建议；原理和示例的关键过程保留在页面，不能全藏在备注中。标明真实样本、自拟情境或示意数据，未实测不把示意回答或数字冒充真实输出或效果。
- **验收与例外：** 观众能用实例解释步骤为何产生该结果；示例确实对应机制，示意不证明实际效果。简单方法可以同页完成原理和例子，专家速览或用户明确排除示例可省略并说明；纯结果/决策页不强塞该模式。近似时长和自行估计页数不是删去必要示例的依据，硬约束按主流程处理。

## 多方案比较

- **适用：** 概览、比较方法/产品/方案，为定位差异或选择做准备；先说明是背景定位、比较本身，还是后续逐项展开的导航。
- **叙述与必要信息：** 共同问题 → 同维度描述各选项 → 关键差异 → 适用条件。比较核心思路、对象、条件、成本等真正解释差异的维度，不混用目标、手段与结果作互斥分类。
- **页面与表现：** 并列表格/列块或共同尺度图；同组标题与维度顺序一致，复杂选项可先比较再分别解释，概览不代替承诺的展开。
- **备注：** 展开比较口径、证据来源与条件差异；短时讲述可优先讲关键行，保留完整材料。
- **验收与例外：** 各选项可比深度相近，空项标明原因；条件不同不强行排名，不为形式对称编造不存在的优缺点。

## 过程与系统关系

- **适用：** 说明工作步骤、变化、数据/控制流或部件关系，不一定是需要例解的方法。
- **叙述与必要信息：** 起点/边界 → 环节或部件职责 → 传递/状态变化 → 结果；按实际内容交代分支、条件、反馈与异常。
- **页面与表现：** 流程图、泳道、时间线或架构图；标题说明所展示的过程，箭头区分时序、因果、数据与控制，不把所有关系画成同一流水线。
- **备注：** 接口假设、异常分支及实现细节；影响理解的条件放在相关连线上或节点旁。
- **验收与例外：** 观众可从入口追到结果，跨部件责任清楚，无断路或反向反馈。静态架构不补造时间顺序，无迭代的过程不加循环。

## 结果与论证

- **适用：** 展示研究发现、项目成果或业务证据，支持一个论断。
- **叙述与必要信息：** 问题/论断 → 数据或其他真实证据 → 解释 → 适用范围与局限；收益区分预期和实测，观测与因果推断分开。
- **页面与表现：** 证据图为主，配简短结论；复杂结果可分“结果—解释”，有证据时可用结论式标题。真实图表遵守数据与原图保真规则。
- **备注：** 样本范围、统计口径、计算方法和来源定位，页面保留影响结论含义的关键条件。
- **验收与例外：** 图表真正支持论断，无选择性省略关键条件；无实测数据不生成效果曲线。单纯汇报结果无需另加教学原理与示例页。

## 评估与验收

- **适用：** 判断成效、风险、质量或方案是否满足要求。
- **叙述与必要信息：** 评估目标 → 指标定义 → 判定/测量方法 → 比较条件。区分“测什么”“如何获得判定”“怎样确保公平”；必要时补充成本、误差或正常任务可用性。
- **页面与表现：** 信息少时按职责分区，复杂时分指标页与方法页；可用判定流程、公式和条件表，避免把指标、人工/自动标注及控制变量排成同层清单。
- **备注：** 分母/统计单位、预算、抽样复核和方法限制；关键阈值或成功定义按需要上屏。
- **验收与例外：** 能从输入/观察走到判定，指标口径一致，代理量不偷换为真实成效；没有数据时介绍评估设计，不虚构比较结果。

## 应对与改进

- **适用：** 已说明问题后，解释防护、修复或改进方案如何起作用。
- **叙述与必要信息：** 问题/失效点 → 对应措施 → 作用位置及责任 → 局限 → 验证。区分减少发生概率、限制后果和事后恢复等不同作用。
- **页面与表现：** 问题—措施映射、分层系统图或修复闭环；标题指出解决的问题，措施顺序与前文失效点或系统层次对应。
- **备注：** 实施条件、代价、证据强度和回归测试方法；建议不伪装成已有实验验证。
- **验收与例外：** 每项措施有对应问题及可检查效果，不堆通用建议、不宣称单项普遍有效。对某方法的一句局限/提示可以附在原理页，完整应对方案须重新判断章节归属。

## 决策建议

- **适用：** 让受众选择方案、批准行动或理解取舍。
- **叙述与必要信息：** 目标与硬约束 → 候选及依据 → 权衡 → 建议及适用条件；需要时补行动或待验证事项。
- **页面与表现：** 比较矩阵、决策树或建议卡；标题聚焦决策，不默认改成技术教学。
- **备注：** 假设、权重、预算口径、证据缺口和备选方案细节。
- **验收与例外：** 建议可从依据推导，满足硬约束，未知项如实标明；用户只需决策简报时不强制扩展机制及示例。

## 总结与反思

- **适用：** 结束主体讲解，回收研究、业务、产品或教学演示的主线，并引出迁移问题或下一步。
- **叙述与必要信息：** 回扣目标/主线 → 核心收获及边界 → 反思/应用问题或后续行动；区别总结已有结论与引入新的主体内容。
- **页面与表现：** 总结可用少量并列判断或主线图；反思可用情境/问题，复杂时分开。多页收束板块的目录归属与独立转场按主流程处理；单页简短总结可自带明显收束层级。
- **备注：** 逐项对应前文依据，安排互动答案、过渡及时间取舍；不把必要的新知识只塞进总结备注。
- **验收与例外：** 观众清楚主体已经结束，结论有前文支持；反思依赖已解释内容。结尾致谢/Q&A和参考资料各有职责，不能替代总结，也不要求每稿都设互动问题。
