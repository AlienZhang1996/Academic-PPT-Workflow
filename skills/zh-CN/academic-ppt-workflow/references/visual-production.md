# 视觉制作方法

Step 5–6 读取“缩略图与风格”，Step 7 读取“单页制作”，Step 8 读取“可编辑重建”；Step 8 初检与 Step 9 二次检查都须读取整个 [重建与保真验收](quality-checks.md#重建与保真验收) 并执行适用检查；涉及社会事件案例或其他真实配图时，在规划阶段即读取“真实配图与占位”，不等素材已选定。以下模板为自然语言输入，实际调用遵循当前工具参数与限制。推进条件、授权和产物职责以 [主流程](../SKILL.md) 为准。

## 缩略图与风格

### 网格与容量

默认列数 `c=4`、行数 `r=3`；用户指定时替换。容量 `k=c×r`，候选主网格取前 `min(k,N)` 页，完整总览按展示顺序每 k 页分批。批次数、格位编号与空位全部从当前参数派生，不另写固定容量。采用行优先顺序，空位保持同样大小且不补造页面。

单页区域 w,h 按要求比例；外边距 mx,my、间距 gx,gy、每行格外页码区高度 t 分别记录，未使用页码区时 t=0：

```text
W = 2mx + c×w + (c−1)×gx
H = 2my + r×(h+t) + (r−1)×gy
```

所有页框等宽等高；页码与留白不计入单页比例。总画布不是固定的 16:9 或 64:27。工具画布有限时等比容纳整个网格并留白，不能压缩某行或裁掉正文。提示词不能保证像素精确：出现格位失真时可改为小批/独立预览，再确定性拼版；只有页面完整、边界清楚的小批图才可拆分。预览仍使用摘要，不替代正式单页。

### 候选与公共样式

所有候选使用相同内容、页序与参考约束，变化限于配色、构图、字体气质和图形语言。若首批缺少后文关键图表/复杂页面，可另外选择相同的代表页供各候选验证，并标明是补充样张；不改变完整总览的页序，不让候选各自挑选不同内容。

在实际调用图像生成工具前，为候选明确各自的设计方向，例如信息组织、主视觉位置或图解方式；比较时说明哪些差异有助于当前内容。参考图的层级、视觉焦点、语义图形和留白组织都需考虑，不能只取几个色值。候选不要求每处装饰都不同，但仅换底色、圆角或标题栏的同一套布局不足以完成多方案设计。按内容选择图解，不强求每页有图标、渐变或复杂装饰。

展示摘要保留精确 Title、页面角色、主要要点、必要限定、图形关系与适用的真实素材占位；次级说明可概括，不用伪小字填充。摘要过密时先精简摘要，不反向删减完整大纲。

style 固定实际可用的中/西文与数学字体、色彩、网格和留白；按页面角色固定标题字体/字号/字重/位置/基线、章号与框尺寸、分隔线及页码。位图中的字体不能仅凭提示词宣称已验证。长标题先调整宽度或受控换行，不静默缩小个别标题；需改文案时返回主记录。

```text
制作风格方案 {方案名} 的缩略图，{c}列×{r}行，共{k}格，按行排列。
每页区域 {w}×{h}，比例{比例}；总画布{W}×{H}，边距{mx,my}，间距{gx,gy}，页码区{t}。
参考{实际传入图片及用途}，风格{方向}；全部页框等大，不改变行高。
格位内容：{格位、slide_id、精确标题、页面角色、摘要、必要限定、图形关系}。
素材占位：{适用页的素材 ID、区域/比例、标签或待选状态}；保留相应布局，不生成假新闻图文。
空位{列表}维持原格位，不显示虚构页面。优先呈现标题与结构，不新增事实或伪文字。
```

## 单页制作

全套缩略图通过后，从完整逐页记录调用图像生成工具独立生成页面。将已查看的选定缩略图作为实际视觉输入，说明对应格位与参考用途；必要时按工具规则提取对应格供参考。缩略图引导设计而不提供正文，不能用其模糊文字恢复内容或直接放大交付。输出分辨率按目标展示尺寸和正文/标签可读性选择，检查实际比例与内容边界。除主流程中的明确例外，逐页都须有独立的生成设计输出；不能只生成封面或装饰资产、其余页套固定代码模板。

按内容特点预先选方法，无须等待失败，但混合方案仍保留图像生成的页面设计：

- 生成工具负责整体构图、视觉层级、语义图解及适合生成的图形；不能把固定坐标模板写完再用缩小截图冒充设计探索。
- 中文密集、公式、精确数据图或公共标题，可直接采用“生成页面设计＋确定性文字/图表/素材合成”。预先划定精确区域，在已生成设计中按其位置、尺度与层级合成，不能只留下一个生成装饰就把主体重新排成简化模板。保存生成底稿、合成区域及最终图；可复用已构建对象，但后续易重建不能反向牺牲当前设计。
- 有数据的图表由源数据绘制；科研原图与证据素材保留原件、来源及必要标注，不用模型重画来改变数据、曲线或真实信号。无数据时可保留图片，不能猜数据重建。

混合方案遵守工具规则；清理被替换的旧文字，检查覆盖面板、默认阴影和遮挡，不产生双重标签。只含少量原生文字的中间文件不能称为全稿可编辑版。

工具无法完成生成时，记录实际发现/尝试及限制，先完成内容与素材准备，可交付已有合法产物和生成计划；不以工具受限为由自行另做程序化整稿。用户明确改选纯原生或代码方式时执行该方式并登记生成项不适用。既有页面的局部修复、精确科学图和 Step 8 原生重建不受新建整页生成要求限制。

```text
单独制作 {slide_id}，页面比例{比例}，目标展示尺寸{尺寸/可读性要求}。
参考{图片及格位}的风格与构图；以完整内容记录为准。
角色{角色}；标题{精确标题}；正文与标签{确定文案}；数据/单位/公式{核实内容}。
结构{节点、关系、连线与布局}；公共样式{本页相关参数}。
设计意图{本页视觉焦点、阅读路径、图解作用及角色层级}；保持参考方案的设计质量。
独立合成的文字/图表/真实素材区域{列表，如有}；占位素材{ID、位置、比例及标签，如有}。
保持确定文案和必要限定，清晰重建文字/图形，不继承预览中的错字、伪影或畸变。
为完整表达可调整留白与细部布局，保持整套风格；不生成页面外的拍摄场景。
```

生成后按 [单页验收](quality-checks.md#单页验收) 检查。OCR 只辅助定位，尤其复查中文、人名、上下标、小数、负号、单位与坐标轴。修复生成污渍时保留科研纹理和真实信号。跨页检查公共组件，覆盖相邻页、长短标题与不同批次，不能只相信参数声明。

组装图片 PPT 时，按展示顺序一页一张等比放置，页面尺寸与实际图片一致；比例不符时重新制作或无损等比留白，不拉伸/裁掉正文。将内容主记录中的备注写入实际 PPT；按主流程 7C/7D 提供当前版本的渲染与确认材料。

## 真实配图与占位

社会事件的新闻照片、报道截图和报告封面采用“提前选材—生成时按素材比例占位—重建时填图”，避免模型伪造证据。先按 [社会事件案例](content-patterns.md#社会事件案例) 从页面职责确定配图计划，不能因尚无图片而跳过。此默认仅适用于这些配图，不扩展为所有图表必须占位。

1. 选材时登记 asset_id、页 ID、原图/来源与日期、像素尺寸、关键区域和展示意图。网页截图仅在页面本身有展示价值时使用；找不到素材则标为待选。
2. 按已核对原图或展示区域设计占位框，记录位置、比例、图注和预定裁切；待选素材的比例标为暂定，核实后校准，不靠裁掉关键信息迁就任意框。计划进入缩略图与单页提示；生成阶段只画明确占位，不绘制假新闻文字。
3. 7D 提供占位清单及已找到的原图/来源，待选项明示。当前仅停在图片版审阅、后续仍计划可编辑重建时，保留这些占位供审阅；最终交付范围明确只有图片版时，需合成真实素材再交付，用户明确要求保留占位则例外。无论阶段，图片细节若是理解论证的必要证据，应提前合成真实素材。尚未找到素材不能宣称已填充或全部完成。
4. 用独立图片对象填充，默认等比完整容纳；确需裁切时保留主体、关键文字及上下文。检查来源、清晰度、图注和裁切。
5. 计划内替换按原素材验收，其余区域仍对照原视觉基准；通过后同步交付图片及预览，保留原占位基准与替换记录。超出计划的内容/布局改变按主流程的修改规则处理，不自动要求重新确认整稿。

生成图若在占位区出现伪新闻或不可信装饰，修复为约定占位；不能仅因手头已有真实截图就提前填图。是否合成仍按第3项的交付阶段和证据需要判断，并记录适用依据。

## 可编辑重建

### 元素拆解与对象选择

使用入口已核对的内容记录、视觉基准和授权。以页面宽高归一化测量位置、尺寸、层次、颜色、样式及分组；识别背景、文字、基础图形、图标、插画、数据图和连接关系，避免把同一图片中的所有元素统一描摹。未确定参数标为估计，靠实际渲染校准。按元素而非整页判断复杂度：复杂插画可保留位图，与其组合的独立简单图标、文字、框体和连线仍分别重建；不能因整页风格复杂而统一截图。

| 元素 | 优先方式 |
| --- | --- |
| 文字、标签、页码 | 原生文本框与文字 runs |
| 框、圆、编号、线条、箭头 | 原生形状、文字和连接线；特殊轮廓难以匹配时用手绘 SVG / 原生路径 |
| 表格、流程 | 原生表格或语义分组的形状/文字/连线；特殊边框可组合补足 |
| 有源数据的常规图表 | 原生数据图表；确实无法匹配时用有数据依据的原生形状并记录编辑方式 |
| 图标、装饰符号 | 手绘 SVG 或原生矢量路径；简单结构可组合原生形状 |
| 底纹＋图标等混合元素 | 拆分选型，完成后语义分组 |
| 公式 | 分式、求和、嵌套上下标等结构化表达优先采用目标软件的原生公式；正文简单变量可用文字。教学矩阵若需逐格标注/着色，可用语义分组的原生表格或单元格；替代方式按实际编辑能力登记 |
| 照片、复杂插画、无源数据的科学图 | 独立图片对象，保留来源及必要细节 |

优先忠实还原，不能为使用某类对象而改变原图。文字取自核对后的主记录，数值取源数据；图像不能辨认时不猜测。原生对象可编辑内部属性，SVG 是否能逐路径编辑要在目标软件验证，位图仅能独立移动/裁切；按真实能力登记。

先核实目标编辑软件，已有用户偏好不重复询问；未知但不阻碍工作时记录采用的目标与限制。对实际出现的复杂样式或公式，先在代表实例验证对象结构及渲染，再扩展复用。当前构建库没有便捷接口不等于目标格式不能实现；必要时检查可用的原生格式能力或其他构建方式，不直接改成截图、纯色或散落文本框。实际做不到时按 [重建替代与保真损失](quality-checks.md#重建替代与保真损失) 记录具体限制，不伪造尝试。

### 几何、色彩与文字

- 测量圆角半径与尺度、描边粗细/颜色、透明度、渐变及内边距；按实际宽高换算工具参数，不依赖统一默认圆角比例。连续渐变核对颜色过渡、方向和作用范围；文字渐变不能默认改为逐字纯色色段，渐隐框线不能默认补成完整实线。
- 在干净底色区域取样，排除文字、边框、子卡片与噪声；被遮挡时参考邻近同类区域再核对。保留白色卡片、语义色差和明显渐变，不全稿盲目加深。
- 区分对象外框 / SVG viewBox 和可见轮廓。按可见内容恢复与底纹的相对位置，居中意图才微调视觉重心，保留有意偏置。
- 核对实际字体及替换、字号、字重、字间距、行距、换行、基线和垂直位置；避免用过大负字间距硬塞文字，末尾字符、公式与边框保持相应留白。
- 恢复表格行列、合并、分隔线和完整高亮范围；保留流程端点、方向、反馈路径与层次，避免缺边和非预期穿线/遮挡。核对虚线节奏、线端、局部强调、柔和透明效果与层叠关系，不以默认形状替换后“语义相同”判定保真。
- 保留逐页背景和装饰的具体构图及裁切。复用公共背景需确认原稿确实相同；不能以同风格的共享或重新生成背景替换各页原图。位图背景清字时避免连同邻近纹理、框线与图案一并改变。

### 图标、复杂资产与复用

先比对原稿具体变体、部件、比例、线宽与负空间，不用大致同义的库存图标代替。提取局部时保留适当边距并检查触边部件；不能一律删除触边连通区域，缺损时先扩大裁切复查。

图标分别验收还原准确性与绘制质量。导入前查资产、导入后查实际底色；必要时用浅/深背景找出白边、异色、断裂和残留。区分有意白色部件/孔洞与伪影，不以去污为由删除真实细节。

复杂插画可抠取为独立图片；文字/连线尽量单独重建，避免残字与原生文字重叠。用户明确要求复杂图案矢量重建且手绘难以还原时，可使用当前可用的 Vtracer 等描摹工具；检查轮廓、孔洞、色块、曲线与节点，清理后导入渲染。工具不可用或结果不合格如实记录，生成 SVG 不等于完成。

重复组件先验证代表实例及实际存在的变体/底色，再复用稳定 asset_id。不同变体分别登记；修改资产检查全部引用页，发现同类缺陷按资产、样式或重建方法扩展排查。构建完成后先在 Step 8 按整个 [重建与保真验收](quality-checks.md#重建与保真验收) 做完整初检与修正，保存初检修正版，再进入 Step 9 二次逐页检查；代表实例通过不能代替任一轮的完整检查。
