# 验收标准

按当前阶段读取相应小节；方法见 [视觉制作](visual-production.md)，记录结构见 [检查与修改记录](project-templates.md#检查与修改记录)。每项状态区分通过、未通过、未验证与不适用，后者说明理由。授权与暂停规则只引用 [主流程](../SKILL.md#确认与修改范围)，不以检查记录代替用户确认。

## 内容与逻辑验收

- **整稿：** 目标、受众与章节职责相符。区分硬性上限、近似目标与自定规模：硬约束须满足，初稿为完整讲解合理超出近似目标时说明原因及真实估时，不以固定自定页数删除必要内容。逐章核对中心问题与观众任务，不能仅以“章名含有这些词”判归组合理；独立评估、应对或决策任务是否应分出板块需有实际依据。先核对用户要求与主流程默认结构，再核对大纲，不能以自行删减后的大纲反证齐全。所有主体及收束页都有清楚归属；多页总结/反思板块也检查目录与转场。多章节稿的独立小节页与目录一一对应，合并/省略符合主流程例外。
- **章节：** 连读实际页序下的 Title 和页面作用，判断为何从前页推进到本页，是否有重复、跳步或未交代的前提。将目录/概览列为讲解范围的并列主题映射到展开页，检查共同框架和可比深度；自行标“聚焦其中一项”或只把其他分支写进备注不能代替完整页面。用户限定范围与仅作背景提及的内容按实际范围检查。
- **页内：** Title、问题与结论各司其职；逐组判断描述点为何回应页面目的，并列是否采用共同维度与相近层级，递进是否有中间环节，批注是否正确从属。箭头、分组与布局表达真实关系；所有关键词都出现不等于关系成立。
- **内容完整：** 主记录写全上屏文案、图形标签/关系、必要限定和备注，不能把关键词大纲交给图像模型补写。
- **讲解充分：** 按适用的 [内容模式](content-patterns.md#模式索引) 核对必要信息，不以“一主题一页”或“同样都有四个要点”代替。需例解的方法逐项对应具体输入/情境、中间变化、结果与原理步骤；综合练习、空白问号或“给出若干例子”的描述不能补足未展示的过程。同页完成或省略有受众、内容或用户范围依据，不能仅因近似时长而删去必要例子。
- **同组一致：** 并列主题的标题句式、术语、说明维度与顺序相近，便于横向对照；只统一编号不算完成。具体机制差异允许不同图解，不强制所有页同一版式。
- **证据：** 数据、公式、单位、条件和来源准确；事实、推断与示意区分，口径不混淆。需要读者当场理解的限定在页面，其余说明已安排进备注。
- **案例素材：** 从社会事件案例页反查配图计划，而不只检查已有资产。过程、实际影响和报道/报告配图或占位均有安排；省略有具体依据。待选仍是待选，不能由“无待填占位”推断素材工作已完成。
- **讲述路径：** 有选讲安排时，完整材料未缺分支，重点/简讲/可跳页与预计用时清楚；按每条现场路径读一遍，核对必要前提、实际跳转及备注过渡。不能以材料较长为由伪报现场时长，也不能把选讲建议只留在外部文档。

以上判定引用具体章/页及主记录中的依据，问题标明位置与修正结果。页数、角色齐全、事实正确、文件校验均不能替代语义检查；结构或逻辑缺口修正后才进入视觉阶段。示例：“机制、评估与治理”虽名称齐全，仍需判断是否把不同观众任务挤进一章；三方法都列了原理，但具体过程只演示一种，仍需检查其余方法是否讲清；“上一页实验”必须对照实际上一页。检查这些关系，不固定通用章数或页数。

角色按实际功能检查：封面明确主题，目录呈现路径，转场交代章节，正文解决问题，总结回顾内容，结尾收束主讲，参考资料支持溯源。角色标签本身不证明功能成立；信息过载先调整表达，不能以字号过小换取形式齐全。

## 设计与流程验收

Step 5–7 的以下检查与文字准确、文件正常分别判定；调用了生成工具也不自动代表设计合格。

| 维度 | 可观察的依据 |
| --- | --- |
| 生成流程 | 有实际生成输入/输出，参考图实际传入；全稿设计预览先于正式单页，单页可追溯到选定方案/格位。无适用例外时，程序输出 PNG 或渲染 PPT 不能充当生成记录 |
| 候选差异 | 相同内容下可说明构图、视觉组织或图形语言的实质区别；仅换色、框角或标题栏不算完成三套设计。单套例外记录理由 |
| 参考适配 | 对照参考图的层级、图解、视觉焦点与留白组织，既体现风格又适应当前内容；不能只以配色相同判通过 |
| 页内表达 | 主次和阅读路径清楚，重点有焦点，图形承担关系或解释功能；文字卡片适用时可用，但不能把适合图解的全稿机械套成卡片列表 |
| 整稿节奏 | 章页实际展示章节名称及本章问题/范围，构图与正文有可见区分；封面、正文、总结、结尾角色清楚且风格统一。角落章号不能替代章页 |
| 混合保留 | 精确内容合成保持生成设计的结构与层级，没有为复用代码或便于重建而另换简化布局 |

同时看全稿总览和典型页面：封面、章页、内容密集页、图解页、结尾中实际存在的角色，并检查不同生成批次。问题按具体区域记录；避免仅写“美观通过”。空白多寡、图标数量或装饰复杂度不是通用质量分数，判断须联系本页信息与参考风格。

## 缩略图验收

- 当前 c、r、k 与映射一致，完整总览内每页恰好一次，空位保持尺寸；补充风格样张另标，不混入页序。
- 实际页框等宽等高且符合单页比例；检查内容边界，不只看总画布尺寸。允许有记录的像素取整误差，不允许明显行高差异或拉伸。
- 精确标题、角色、主要内容、必要限定、关键关系和案例占位与主记录一致；摘要可省略次级说明，不改变主旨。
- 风格与同类公共标题/章号/分隔线一致，足以选择方案和判断整体布局；未用伪文字或伪新闻填充。
- [设计与流程验收](#设计与流程验收) 的适用项通过；章页结构与风格选择在正式单页生成前落实。

细字、复杂公式和非关键局部纹理可留待单页核对；标题错误、缺页、主旨或几何错误必须先修。此阶段通过不等于全部内容已经验收。

## 单页验收

逐页将当前完整内容记录与当前图片核对，覆盖：

| 维度 | 通过依据 |
| --- | --- |
| 内容与文字 | 确定文案、数字、符号、标签和必要限定准确呈现，仅合理排版空白改变；图形关系忠实，未擅自改写正文 |
| 事实与关系 | 数据点、曲线、轴、单位、公式及条件有依据，节点/连接方向正确；OCR 检出词语不能代替关系检查 |
| 画面 | 无错字、乱码、伪影、意外污渍、残留标签或畸变；真实科研纹理未被误删 |
| 可读性与比例 | 在目标显示尺度可读，实际像素比例及内容区域正确，无拉伸、正文裁切、遮挡或过度缩字 |
| 跨页样式 | 同类标题、编号框和分隔线的实际大小/位置一致；覆盖相邻页、长短标题和不同批次，参数声明不代替输出 |
| 真实素材 | 从案例页核对配图决策无遗漏；素材真实性与填图阶段分别检查。后续仍要重建的图片审阅稿按计划保留占位，提前合成须有视觉参考中的适用依据；待选/省略如实记录，需理解证据细节的区域没有用空框代替 |
| 设计与流程 | 上述设计验收的页内表达、角色层级、参考适配及生成/混合记录通过；内容清楚或渲染正常不能代替这些项 |

检查记录可按页聚合，仅问题区域详记。修正后复核整页，防止补一处丢一处。组装图片 PPT 后检查页序、比例、图片版本、实际备注与渲染，选讲和跳转说明也需实际写入对应页。核对内嵌图片与最终单页的对应关系、实际尺寸及有无降采样；必要时比较媒体字节或哈希。PPTX、PDF 与预览的大小分别报告，不以文件 MB 数或放大像素数证明清晰度与生成质量。7D 展示这一版本的图片、预览及占位材料，按主流程决定是否继续。

## 重建与保真验收

Step 8 与 Step 9 均须读取并执行本节全部适用标准：文件与编辑能力、元素与关系、实际渲染对照和逐页检查方法。Step 8 完成重建后的完整初检、修正与回归；Step 9 以初检修正版为输入，再次完整检查全部适用页面。两轮共用标准，但分别记录版本、发现与结论；结构、保真和成品质量分别判定，不能以第一轮通过代替第二次实际检查。

### 文件与编辑能力

读取本轮待检 PPT 对象，必要时检查 XML/媒体：文件可打开，页数、顺序、比例及文本内容正确；备注实际写入相应页，图表对应源数据；对象无非预期越界、遮挡或截断。原生、SVG、位图的编辑能力分别验证；只有对象数量多或 SVG 嵌入成功不能证明内部可编辑。禁止整页截图覆盖对象、透明文字伪装或裁图残字重复。结构化公式需核对是否为目标软件可按数学结构编辑的对象，而非仅能修改字符的文本框组合；正文变量与有教学用途的矩阵单元按其实际用途验收。

### 元素与关系

| 维度 | 通过依据 |
| --- | --- |
| 对象选型 | 基础图形与简单图标采用适用的原生/SVG 矢量方式；混合元素按部件拆分。位图或替代方式有具体依据，未不必要地降低编辑能力或改变样式 |
| 图标准确性 | 具体变体、完整部件、轮廓、比例、线宽、孔洞和负空间匹配，无裁切缺损 |
| 图标绘制质量 | 曲线平滑，无非预期锯齿、断裂、异色、白边或背景残留，有意白色部件保留；实际底色检查通过 |
| 框体与色彩 | 圆角、描边、填充、渐变、透明度与内边距匹配，无缺边、默认圆角偏差或全稿底色漂白 |
| 风格特征 | 文字/形状的连续渐变、方向、作用范围、渐隐边缘、虚线节奏、线端、局部强调及层叠关系匹配；逐页背景构图和裁切保留，没有统一套默认样式 |
| 对齐与文字 | 按可见字形/轮廓检查圆内数字、符号、图标与底纹的相对位置；基线、换行、字间距与内边距正确，无贴框、截断、残字或文字/清理白块遮断框线 |
| 同组一致 | 对照原图意图检查同排标签、编号、标题、矩阵数值及公共组件的字号、字重、大小、间距与基线；不从各自 OCR 字框独立估算后便认定一致 |
| 表格与流程 | 行列/合并/分隔/高亮完整；箭头线身、箭头头部、端点、方向及反馈路径齐全，未非预期穿字或断连；层次及有意交叉得到保留 |
| 图片与占位 | 图标/照片/纹理无漏部件或裁切缺损，复杂区域无描摹残片；计划填图已替换并核对来源及裁切，有意留白与待填素材分别登记 |
| 复用 | 代表实例验证后复用，变体未混用；共享修改及同类缺陷的检查范围可追溯 |

图标准确性和绘制质量独立判断。导入前资产合格不能代替导入后实际呈现；主题色、透明度、描边与字体替换可能改变结果。

居中应先确认原稿意图；文本框或 SVG viewBox 的中心不等于可见字形/图形的中心。必要时用实际渲染的轮廓辅助测量，不设统一像素阈值，也不强求不同数字的笔画外框同宽同高。保留有意的不对称、层级字号差异和留白，不以“统一”为由另改设计；基准缺陷与重建误差分开记录，改变已认可内容或布局按主流程处理。

### 重建替代与保真损失

两轮均对照原基准与实际 PPT 对象检查，不只查渲染是否好看，也不只读取已有例外清单。重点识别：简单图标被截图、文字渐变被离散色段替代、结构化公式被拆成普通文本、特殊框线被默认形状替换、逐页背景被共享图覆盖。Step 9 重新判断初检保留的替代是否必要，并查出未登记的简化；全稿原生对象数多不证明这些区域合格。

对发现的替代或差异，沿用素材/问题记录登记页与区域、基准特征、当前对象及编辑能力、可见损失、具体理由、实际尝试与证据。按以下情况处理：

- **合理保留：** 照片、复杂插画/艺术纹理、无源数据科研图，或符合用户编辑范围的位图，不要求一律矢量化；仍检查来源、清晰度、完整性、裁切及可独立操作程度。
- **需修正：** 不必要的截图、纯色替代渐变、默认样式替代原设计、公式结构损失，以及其他明显可修复差异。不能仅因“内容正确、可读、能移动”或笼统写“复杂、近似实现、非像素级还原”而通过。所需编辑能力与视觉还原度均需满足任务，不能靠简化或截图只满足其中一项。
- **受限或未验证：** 写明实际工具/格式/资源限制、已尝试方法和影响；不能把库接口缺失直接等同格式不支持，也不为证明困难盲目试遍所有工具。按完成条件标记受限产物，不用免责声明将未达到的要求改成通过。

细微抗锯齿差异不自动要求修复，也不将合法位图保留视为降级；但可见风格损失不能被归入“非逐像素一致”后放过。记录与尝试按实际问题聚合，不要求为每张正常照片制作失败实验。

### 实际渲染对照

从待交付 PPT 实际渲染，与独立视觉基准按相同页面比例与尺度比较：总览检查跨页一致性，整页检查布局关系，局部检查文字、图标和边框。局部采用相同裁切区域和显示比例，不能分别裁紧再放大到同样大小掩盖位置/尺寸偏差。必要时用叠加、闪烁或差异图定位；相似度仅辅助，背景一致不能抵消局部错误，抗锯齿细差也不等于内容错误。

计划填图区域按真实素材检查，未改区域继续对照原基准；成品渲染副本不作为新的独立保真证据。已批准的基准变更保留旧版本与原因。没有原图的局部修改按任务目标核对，原图保真标为不适用而非通过。

验证环境须区分目标编辑软件与实际渲染工具。若存在原生对象和兼容显示分支，分别注明检查了哪一分支；PDF/兼容分支正常不能证明原生公式、渐变文字在目标软件中正常。目标软件可用时，对相关代表对象实际打开并做最小编辑、保存及重开验证（在测试副本中），再复核影响页面；检查字号、字形、基线、边界及结构是否保持。目标软件不可用时继续可做的结构和渲染检查，目标环境的显示/编辑标为未验证，不以 XML 存在或其他软件的 PDF 代替。具体文件格式操作按实际环境查证，不强制同一平台实现。

### 逐页精查流程

以下方法供两轮完整检查使用：Step 8 完成初检修正后交接，Step 9 再次检查后验收交付。第二轮不是只复核第一轮问题清单；即使初检没有发现问题，也须重新查看全部适用页面。可复用对应版本的渲染材料，不复用第一轮视觉结论来替代第二轮检查。

1. **核实本轮输入。** 登记本轮阶段、输入 PPT、独立基准、内容记录及计划替换的版本，重建流程的 Step 9 核实输入为初检修正版；在实际渲染环境打开并导出，确认页数、比例、字体替换和文件身份。接续时已有渲染只有在能对应当前 PPT 且版本/环境适用时才可复用，不能沿用旧版“通过”结论。无法渲染时继续可做的结构检查，视觉部分标为未验证。
2. **通查并形成修改前清单。** 全稿任务每页都实际看整页，按“元素与关系”检查；复杂流程、密集文字、细框线、公式和疑似缺陷再放大。之后跨页看公共组件、同组看编号和标签的一致性，并执行 [重建替代与保真损失](#重建替代与保真损失) 检查，不能只核对文字、关系和遮挡。每页记录具体发现或已检查未见明显问题，问题附区域、原状态及对应渲染；不先批量修完才倒填发现记录。纯自动越界/重叠检测、OCR、差异分数和“已有对照图”均不能代替逐页视觉判断，脚本不自动给所有页填视觉通过。
3. **集中修正并复核。** 在授权范围内修正可编辑对象；复用资产、字体、文字清理或描摹方法导致的问题，检查全部相关实例。重新导出受影响页面后，核对修复点、整页和邻近未改元素，并复核正文、公式/数字、照片及备注是否意外改变。修复造成的新问题继续处理；本轮已查、未改且未受公共组件影响的页面可引用本轮证据，不能跳过第二轮逐页查看，也不能因修复一页宣称全稿重新通过。
4. **核对本轮结果。** 汇总每页检查覆盖、问题的修复与复核证据、未解决项；Step 8 初检通过后保存修正版与记录，进入 Step 9，不作正式交付。Step 9 完成第二轮后，按“文件与编辑能力”核对最终对象与内容，确保本次交付的 PPT、预览、备注、记录及其他副本对应同一版本，不因此增做未要求的格式。标明实际验证的软件/字体环境，未测试的 PowerPoint/WPS 等环境不能宣称通过。满足“修正与完成条件”才正式交付，否则标注候选/未验证状态和具体限制。

占位按用途验收：计划替换的新闻/论文配图不得无说明遗留；课堂填写区、空表或用户要求保留的模板空间应保留。新提出的填图需求与原计划漏填分开记录，不把所有空框都当缺陷，也不为补齐空框伪造实验结果。

## 修正与完成条件

适用于大纲、缩略图、单页、重建及逐页精查：保留连续的问题与修复证据，不设固定修正轮数。按事实/内容错误 → 不可读或遮挡 → 可见结构与样式差异 → 局部细微差异处理；用放大定位，结合目标显示尺度判断。明显且可修复的偏差继续修，不以差异说明代替修复，不承诺未经验证的 100% 还原。

同一缺陷经当前方法处理仍未改善时分析原因、换方法，不机械重复。实际能力或用户资源边界阻止继续时，记录已尝试方法、未解决项和影响，可交付标注状态的草稿；资源用尽不等于通过，也不扩大付费或外部操作授权。

修复后重渲染受影响页；公共组件修改检查全部引用页。同一资产、样式或方法导致的缺陷应检查相关其他实例，不限于用户标注。表现调整同时核对正文、数字、备注、已有图片和邻近未改区域；有意内容变化另记。同一轮修复中，已查且版本未变、未受关联修改影响的页面可复用本轮证据，不必每次局部修复都重做全稿；这一规则不免除 Step 9 对全部适用页面的第二次实际检查。

增删/拆分/重排页面、替换案例或改变讲述范围后，重新检查受影响章节的职责与覆盖、实际前后页及选讲跳转，并同步目录、概览和备注中的“上一页/接下来”等指代。只同步文案文件、保持页 ID 或通过组装检查不能证明衔接仍成立；此项不要求纯表现修复重做未受影响的内容规划。

扩展检查不自动扩大修改范围：用户限定只改某页时，关联页可检查并报告发现，实际改动仍限于授权对象；共享修改会影响其他页时优先隔离为局部实例。

当前阶段的必要检查全部通过才推进；结构、事实、逻辑、视觉保真、编辑能力和实际渲染的状态分别登记。无法渲染时，结构检查仍可继续，但实际渲染及依赖它的视觉检查标为未验证，不能用生成原图或源码截图代替。交付文件、预览、备注及证据须对应最终版本；仅交付用户要求范围内的产物。
