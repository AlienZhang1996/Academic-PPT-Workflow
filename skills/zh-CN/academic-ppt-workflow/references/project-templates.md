# 项目记录

按当前阶段读取相应小节。Markdown、JSON 或构建脚本数据均可；字段可合并，不适用项可省略，但适用的规划与验收信息不能省略。内容只保留一个主记录，其他视图按 slide_id 引用或生成。

## 最小记录

- **新制作：** brief 记录目标/受众、语言、时长/页数、比例、风格、交付与编辑范围、材料/缺口、执行模式、当前阶段与终点。时长/页数分别标明用户硬性上限、近似目标或自行估计，不把估计升级为要求；初稿合理超出近似目标时记录新增内容的必要性及预计用时。
- **接续：** 读取当前主记录、基准/成品路径与版本、完成状态、授权和未解决问题；核实现状后补必要缺项。
- **外部重建：** 原始输入、页序/比例、核对后的文字/数据与已有备注、当前输入检查、基准及直接重建授权。没有来源支持的事实标明未核实，不伪造研究记录。
- **局部修改：** 当前文件、修改要求、目标页/对象、比较依据、关联资产/样式、检查结果与新版本；无需补建完整大纲。

仅关键缺项需要提问。记录实际工具与限制，输入只引用或复制，不覆盖。产物可按以下职责组织，路径不强制：

```text
brief.md / outline.md / style.md / checks.md  # 在需要时创建；可合并为结构化记录
research.md                                  # 仅实际调研后产生
thumbnails/                                  # 摘要、候选、网格映射
slides/                                      # 完整单页与保留的视觉基准版本
assets/                                      # 数据、真实素材、复用组件
source/ / renders/                           # 构建代码/依赖、实际 PPT 渲染
reconstruction.md                            # 重建或局部修复按需记录，也可由脚本生成
图片版.pptx / 可编辑版.pptx                    # 名称按项目；标明图片文件的职责与版本
```

## 逐页内容记录

新制作需有完整上屏内容，不能只列关键词。页 ID 稳定，展示顺序单独维护。一个简明结构即可：

```markdown
# 大纲
- 版本、目标/受众、总页数/时长、比例：
- 整稿主线、章节顺序和衔接：
- 各章的中心问题/范围、与前后章的关系、对应页 ID；总结/反思等收束内容的归属与转场：
- 目录/概览承诺的并列主题 → 各自讲解单元及页 ID、共同标题与说明框架：
- 适用的内容模式或自定义组织方式；需例解的方法 → 原理与具体示例所在页 ID，同页或省略理由（如适用）：
- 已确定的页面角色安排、合并/省略理由、主讲结束与参考资料位置：
- 有限时要求时：完整材料与现场讲述路径；重点/选讲页 ID、用时及必要过渡：
- 来源索引（原始材料与实际检索来源分别标识）：

## slide-id
- 展示顺序、角色、所属章（如有）：
- Title（精确文字）：
- 本页在章内的作用；必要时分别写核心问题、核心结论：
- 与实际前后页的承接（转场、依赖或范围变化；可引用相邻记录）：
- 完整上屏文案：正文、信息性批注、标签、数字、单位、公式和必要限定
- 页内关系：各描述点如何回应 Title、采用什么共同维度或递进/从属关系
- 图形关系：节点/连线含义、并列/递进/因果/对比/层级；无图则省略
- 讲者备注：展开解释、详细口径/计算方法、来源定位；适用的选讲建议、跳转与用时；与上屏内容分开
- 所用来源、数据及素材 ID：
- 社会事件案例：配图计划/待选状态，或不配图的具体理由：
```

三层关系可用短句或映射记录，不重复抄写正文；同一承接关系只需记录一次。内容模式按讲解单元登记，不强迫每页贴标签或另填整套表；原理与示例若在同页，说明具体区域及信息对应，不能只登记“有例子”。前置知识、标题类型理由等有助于消除歧义时再加；封面无需强造核心结论或分点关系，首尾页没有前页/后页则省略。主记录确定了使用图形表达的信息，不要求再以正文重复。选讲路径引用完整材料中的页面，检查跳转不缺必要前提；完整材料时长可以长于现场路径，两者分别统计。

目录、标题链和缩略图摘要从该记录派生；不要独立维护重复标题。标题链保留页 ID、章归属、Title 和页面作用，供连读检查。摘要保留角色、精确标题、主旨、必要限定、图形关系及适用的素材占位，引用未展开的内容即可。任何确定文案的改写先更新主记录再同步派生物。

research 可用“发现/论断—来源定位—日期/条件/单位—事实或推断”记录，并列出未解决问题；没有实际检索时不创建研究报告，直接引用输入来源。

## 风格与页面映射

style 保存参考/选定方案、实际可用字体、配色、字号层级、网格/留白与公共组件参数。参数按角色分组，包括标题/章号位置与字号、框尺寸、分隔线、页码；长标题处理与例外按需记录。

另记参考图的主要设计特征、各候选的构图/图形语言差异与选定理由。多章节稿登记“目录章节 → 独立小节页 ID”；适用的合并/省略须记用户要求或具体约束，不能只记“短稿”。

网格记录 `c,r,k=c×r,w,h,mx,my,gx,gy,t,W,H` 及实际画布尺寸。每批格位为 `1…k`，登记对应 slide_id 或空位。风格候选主网格、补充样张、完整总览与成品预览分别标注用途及所依据的版本，不能混入同一展示序列。

## 素材与重建记录

素材清单按需采用下列字段，可直接使用构建脚本数据，不重复手填；社会事件案例的配图决策需从内容记录可查，不能因清单为空就跳过：

| 字段 | 内容 |
| --- | --- |
| 身份与复用 | asset_id、来源/基准区域、版本、具体变体、引用页/对象 |
| 真实配图 | 原图/链接、日期、像素尺寸、关键区域、显示意图、图注与备注 |
| 占位替换 | 页内归一化位置/尺寸、适配/裁切依据、预定范围、待选/占位/已展示/已填充状态 |
| 重建方式 | 原生 / SVG / 位图、目标编辑软件与实际编辑范围；公式区分结构编辑和普通字符编辑，适用时登记兼容显示分支 |
| 替代与近似（如有） | 基准特征、当前实现、可见/编辑能力损失、具体理由、实际尝试及证据、需修正/合理保留/受限未验证判断；关联 checks 问题 ID |
| 几何与样式 | 对象外框与必要的可见轮廓；层次/分组、文字样式/间距、填充取色/渐变、描边、圆角及测量尺度 |
| 验证 | 代表实例、裁切边界、准确性与绘制质量检查；引用 checks 问题 ID |

只记录影响重建的属性，不把每个像素或装饰笔画列为内容。图像无法确定的参数标为估计，待渲染校准。保存实际生成提示、参考输入及可获得的工具信息，不伪造型号、种子或成功状态。

新建稿的生成记录按候选/单页 ID 保存：实际工具、提示词、实际传入的参考图与格位、生成输出路径/版本、检查结果。混合页再记生成底稿与精确合成区域；代码拼版和 PPT 渲染另标用途。记录可由调用日志派生，不必重复填表；但无生成调用的代码绘图不能登记为模型生成。全套预览检查与正式单页的版本先后须可追溯。

交付清单区分 PPTX、PDF、预览与单页原图，记录最终路径、版本/页数、实际文件大小和单页像素尺寸；注明组装或导出是否重采样，不把提示词中的请求尺寸当实际尺寸。图片来源及对应关系可由媒体清单或哈希核对，文件体积不作为生成质量门槛。

## 检查与修改记录

可按页与问题 ID 聚合，不要求并行维护多套验收表：

```markdown
# 当前状态
- 本次范围、阶段/终点、实际工具及能力限制：
- 内容/风格版本；独立视觉基准路径与版本；候选/最终 PPT 路径、版本或哈希及当前渲染路径：
- 目标编辑软件；实际渲染软件/版本、字体环境、页数/比例；有兼容分支时说明实际检查的分支，未验证的显示/编辑能力：
- 重建完成、Step 8 完整初检及 Step 9 第二次检查的状态分别记录；各轮输入/修正版与逐页检查范围：
- 授权/确认的用户原指令、对应版本与范围；待确认或可继续的依据：
- 已批准的基准改动、计划素材替换及适用范围（如有）：

# 页级验收
| 阶段/轮次 | slide_id | 本轮各适用维度的状态 | 修改前发现/已查未见明显问题 | 整页/局部证据及输入版本 | 未解决问题 ID |
| --- | --- | --- | --- | --- | --- |

# 问题与修复
| ID | 发现阶段/轮次及页/区域 | 修改前问题、严重性与原因（未知可留待诊断） | 修改及修正版 | 同类/引用页检查范围 | 修改后渲染、回归证据与状态 |
| --- | --- | --- | --- | --- | --- |
```

状态使用通过/未通过/未验证/不适用及理由。内容覆盖可按页引用主记录，遗漏处详记；内容正确、设计质量、生成流程、文件组装与重建保真分别记录，不互相代替。证据注明对应版本，局部对照记录相同裁切范围与显示尺度。

Step 8 与 Step 9 沿用上述记录并按轮次追加，不覆盖初检历史。各轮先保存范围内全部页面的修改前发现，再修正并复核；无明显问题的页面也登记实际检查证据。第二轮说明输入如何对应初检修正版；即使复用相同渲染图，也记录本轮重新查看的结果，不能复制第一轮“通过”充当复查。位图保留、替代实现与近似项按实际对象再次判定，注明沿用/改变处理的依据；未登记但发现的简化补入同一记录，不另建平行清单。局部任务只覆盖目标与关联影响，审查任务不自动改稿。记录可引用已有日志，不要求每个正常元素单独建表；脚本可汇总覆盖与版本，不能自动判定视觉通过。无法渲染或证据与当前文件不对应时标为未验证，不倒填检查结论。

大纲验收记录章/页 ID、对应职责或覆盖依据、判定及未解决问题；可引用主记录中的关系和映射，不另复制一套大纲。仅列“章页齐全、事实正确、逻辑通过”不足以证明叙述连贯。

修改记录区分内容变更、表现修复与计划填图；表现修复后的正文/数字、备注、已有图片及邻近区域做回归。记录未变页在同一轮内复用证据的版本依据；跨轮可复用渲染材料，仍须重新检查并保留各轮结论。另记最终交付与残余限制。独立基准、批准的局部变化和成品渲染副本始终分别登记。
